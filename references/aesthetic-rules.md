# 审美硬规则（脚本自检 + Agent 看图批改）

用户的判断：zine 的审美就是表达本身；「像明信片」= 没有审美。这些规则是从「为什么之前像明信片」反推出来的。

## 脚本会自检的（写进 `版式清单.txt` 末尾 ✓/✗）

1. 最大字 ≥ 最小字的 30 倍（尺度反差）。
2. 全书至少 1 个满版跨页。
3. 至少 1 个跨页的图形来自照片本身（抠图轮廓 / 边缘线 / 色带 / 亮度曲线）。
4. 相邻跨页手法不同、家族不同。
5. 每张照片都用上（自检第 2 条）；同一张最多 2 次，第二次换家族；重复张数 ≤ max(2, 照片数 / 5)（自检第 3 条）。
6. 页数是 4 的倍数（不够就补呼吸页，不拿旧照片凑数）。
7. 印出来标为「原话」的字，都能在 `said` / `chapters[].said` / `notes` / `title` 里找到原文。
8. 同一句原话在正文里最多印 2 次（页眉标题、填进人形 / 字河 / 圆圈里的纹理字不算）。

脚本输出共 9 行 ✓/✗（第 5 条拆成两行）。

## 禁用组合（不是禁元素）

- 「中等大小照片 + 白边 + 居中」—— 明信片感的来源。
- 徽章阵列：4 张等大白边圆角图 + 波浪线 + 彼此无关。
- 填空色块：≥40% 纯高饱和 + 一个圆图 + 没有真实文字。
- 复制跨页：同一张图左右各半。
- 朋克 / 强反叛视觉（撕纸勒索信字、骷髅、粗暴黑白复印）——用户明确不要。

## Agent 看图批改（必须做，不能只看自检）

出图后打开 `总览.jpg`，逐个跨页检查：

- 大字有没有被裁掉、被照片盖住、和别的字撞在一起
- 浅底上的浅字 / 深底上的深字（看不清）
- 抠图的直边露出来（主体被画面边缘切过）
- 同一句原话在整本里刷了好几次
- 两个不相邻的跨页长得几乎一样（同一手法用了两次）→ 用 `avoid` 排除它
- 颜色和原话打架（说「冷」却印在暖色卡片上）
- 第一眼能不能感到用户说的那个感觉；读回差得多就调轴或换手法再跑

发现问题 → 只改 `feeling.json`：换 `big_words`、调轴、`dropped`、`cover`、`avoid`（不想要的手法名，见 `techniques.md`）→ 重跑 → 再看。
至少看一轮；改到「看图没有上面这些问题、读回没有 ← 提示」为止，一般 1–3 轮。**不要改 skill 里的代码**——那是 skill 作者的事；
真改不掉的问题如实告诉用户。
