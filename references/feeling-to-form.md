# 感受 → 版式（v6 的核心）

> 一句话：**照片不变，感觉变，书就变。** 用户不用懂设计词，只说「那天是什么感觉」；
> Agent 把这句话翻译成 6 根轴，再从 6 根轴推出颜色、字、尺度、密度、节奏、照片处理和手法。
> 每个设计决定都写一条「旁注」，回指用户的原话。

## 一、为什么是「感受」而不是「主题 / 模板」

| 现有做法 | 问题 |
|---|---|
| 按主题选模板（旅行 / 生日 / 毕业） | 同一次旅行，有人觉得「热闹」，有人觉得「舍不得」，模板给的是同一个样子 |
| 让用户选风格（Y2K / 极简 / 复古） | 用户没有设计词汇；选了也不知道为什么 |
| Agent 读相册说出一个看法 | 看法是 Agent 的，不是用户的；而且容易落俗 |

zine 的第一性是「一个具体的人在场」。**在场的不是照片，是这个人对照片的感受。**
所以输入是感受，skill 的工作是把感受审美化。

## 二、6 根轴

每根 -2..+2。左负右正。轴名用感受词，不用设计词。

| 轴 | 左（-2） | 右（+2） | 设计上意味着（左 → 右） |
|---|---|---|---|
| near | 隔着一点距离 | 贴得很近 | 照片缩小、四周大片空白、不抠图 → 照片出血、抠出来贴近、字压在物上 |
| warm | 凉的 | 暖的 | 纸偏灰白、取照片里的蓝绿紫 → 纸偏米黄、取照片里的橙红黄 |
| fast | 安静 | 热闹 | 一页一张、多留呼吸页 → 一页挤好几张、贴纸叠放 |
| heavy | 淡 | 浓 | 细字、浅色、低对比 → 粗黑大字、深色大面积、高对比 |
| sharp | 恍恍惚惚 | 清清楚楚 | 轻微失焦、双色、颗粒 → 闪光灯感、饱和、平涂撞色 |
| loose | 规规矩矩 | 乱糟糟 | 对齐网格、不旋转 → 倾斜、叠压、散落的圆点 |

特殊组合：`heavy ≥ 1` 且 `warm ≤ -1`（「天黑了」又「浓」）→ **纸本身变深、字变浅**。

## 三、从轴推出什么（`scripts/feel.py`）

- **颜色** `derive_palette`：只从这一段的照片里取色（不引入外部色）。主色按暖/冷挑饱和度高的那块，
  浓淡调饱和；第二色要和主色色相拉开 ≥ 0.22；深色从照片暗部取并压深。
  `sharp ≥ 1` 或 `fast = 2` 时，平涂色对到最近的 Riso 油墨色（只在明亮油墨里找）。
- **字** `derive_type`：乱+热闹 → 手写体（Hannotate）；浓 → 宋体 Black；淡+恍惚 → 楷体；淡+清楚 → 宋体细。
  浓或热闹时数字/拉丁用 DIN / Helvetica 900，否则 Didot 斜体。大字 = 300 + 30·heavy + 20·near（≥240px），最小字 8px。
- **版面** `derive_layout`：最大倾斜 = 3.2°·loose；每跨页照片数 1.45 → 2.8 随 fast；主图面积 7% → 80% 随 near；
  照片处理 flash / soft / duo / natural 随 sharp。
- **手法** `spreads.score`：每个手法声明对 6 轴的亲和度，点积打分；再叠加审美硬规则（见 `aesthetic-rules.md`）。

## 四、怎么得到轴（三条路，按优先级）

1. **用户亲口说的**（`said`）→ Agent 先查 `LEXICON` 起步，再**用大白话复述给用户确认**：
   「我听下来是：很热闹、很暖、有点乱。对吗？」确认后写进 `axes`，并把依据写进 `because`（必须是 `said` 的子串）。
2. **看图二选一**（`--pick`）：对拿不准的轴，用同一组照片各出一对 A/B 跨页，只改这一根轴，
   让用户「看图选哪个更像那天」。选择写进 `picked`。用户全程不需要说一个设计词。
3. **都没有**：轴全 0（中性），旁注会如实写「在两者之间」。

## 五、分段（一天里感觉会变）

`chapters[]` 每段可以有自己的 `said`、`axes`、`big_words`、`key`（取色照片）。
示例《天快黑了》：吃饱太阳大（暖浓热闹）→ 到处走拍合照 → 天快黑谁都没说话（深色、安静）。
整本的颜色和节奏会随段落变，这是「感受」比「模板」多出来的东西：**模板是静态的，感受有时间。**

## 六、读回（`readback.json`）

成品截图后粗测平均亮度、暖度、饱和度、边缘密度、平坦区域占比，反推 4 根轴（heavy / warm / fast / near），
和用户想要的对照。差 ≥ 1.5 会提示「看看要不要调」。系数只用 3 本示例书粗校，**只当方向提醒，不是精确测量**。
Agent 交付时用大白话说：「你说舍不得，我做出来整体偏淡偏安静，和你说的一致」或「这本比你说的更吵，要不要收一点」。
