# 页序与打印：为什么第 1 页旁边是最后一页

> 一句话：小册子是把一叠纸对折订起来的，所以「屏幕上第 1 页」和「打印机第一张纸右边那一格」是同一个位置，
> 而同一张纸的左边必须放最后一页。这个重排叫 imposition（拼版）。

## 1. 页数为什么必须是 4 的倍数

一张 A4 纸对折一次 → 4 个页位（正面 2 个 + 反面 2 个）。
所以总页数必须是 4 的倍数：8 / 12 / 16 / 20 …
不够时补「呼吸页」（带一句小字的留白页），不要留纯白页。

## 2. A5 骑马钉 2-up 页序公式

N 为总页数（4 的倍数），i 从 0 起表示第几张纸（0 = 最外层）：

```
正面左 = N - 2i      正面右 = 2i + 1
背面左 = 2i + 2      背面右 = N - 2i - 1
```

导出 PDF 的页序 = [Sheet0正面, Sheet0背面, Sheet1正面, Sheet1背面, …]
每面左右页码之和恒为 **N + 1**。

### Golden table（脚本 self_test 每次运行都会断言）

8 页：

```
Sheet 0   正面  8 | 1     背面  2 | 7
Sheet 1   正面  6 | 3     背面  4 | 5
```
展开序列 `[8,1, 2,7, 6,3, 4,5]`

16 页：

```
Sheet 0   16 | 1      2 | 15
Sheet 1   14 | 3      4 | 13
Sheet 2   12 | 5      6 | 11
Sheet 3   10 | 7      8 | 9     ← 中心跨页 8|9
```
展开序列 `[16,1, 2,15, 14,3, 4,13, 12,5, 6,11, 10,7, 8,9]`

**中心跨页**永远落在第 `N/2` 与 `N/2+1` 页，所以 `plan_zine()` 必须把 SPREAD_L/R 固定在这两个位置，
不能先排内容再补空白，否则跨页会偏前、折起来对不上。

## 3. 另一种折法：一张 A4 折 8 页（当前脚本未采用，备用）

A4 横向 2 行 × 4 列，单面印刷，上排整体旋转 180°：

```
┌──────┬──────┬──────┬──────┐
│  5 ↻ │  4 ↻ │  3 ↻ │  2 ↻ │   上排全部倒置
├──────┼──────┼──────┼──────┤
│  6   │  7   │  8   │  1   │   下排正立，P1 封面在右下角
└──────┴──────┴──────┴──────┘
```

每格 74.25 × 105 mm。折法：长边对折 → 纵向对折两次 → 沿水平中缝只切中间一格 → 长边对折 → 两端向中间推压平。无钉无胶。

⚠️ 还有 quarter-fold 双面变体（Front = `8,1,2,7` / Back = `6,3,4,5`，P2 与 P7 倒置），页码表**不通用**。
要做成第二个 preset 时，必须与上面的 2-up 分开硬编码，不要试图用同一个公式。

## 4. 打印设置（用户最容易错的三件事）

| 设置 | 必须是 | 错了会怎样 |
|---|---|---|
| 双面翻转 | **短边翻转** | 长边翻转 → 背面整个倒过来 |
| 缩放 | **100% / 实际大小** | 「适合页面」→ 尺寸缩小、裁切位全偏 |
| 打印机 booklet 模式 | **关闭** | 会二次拼版，页码彻底乱 |

其它：先试印 1 张对折核对；整叠一起折；长臂订书机沿书脊 2–3 钉；
出血 3mm、文字安全边距 10mm、装订留白 3mm、图像 300 DPI @成品尺寸。
纸张家用 80–100 gsm 即可；one-sheet 双面建议 160–180 gsm 哑光。
超过 5–6 张纸（约 40–60 页）会出现 creep 爬移，需要按每张纸向内微移——本 skill 限 20 页内，暂不处理。

## 5. 实现说明（只需一个浏览器）

没有用 pypdf / pdfjam / Ghostscript。做法是**渲染两遍 HTML**：

- `pages.html`：`@page { size: 148mm 210mm }`，按阅读顺序 1…N 输出，浏览器打印 → `按页顺序.pdf`（A5）
- `imposed.html`：`@page { size: 297mm 210mm }`，每张 A4 横向 `.sheet` 里左右各塞一个 A5 `.page`，
  顺序为 N-2s | 1+2s、2+2s | N-1-2s，浏览器打印 → `骑马钉拼版.pdf`（A4 横向）

好处：任何系统只要有 Chrome / Edge / Chromium（或 Playwright）就能出两种 PDF，不需要装 PDF 库。
