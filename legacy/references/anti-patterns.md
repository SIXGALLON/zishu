## 零、判断口诀：装饰能不能留，看三条

| | 该留 | 该删 |
|---|---|---|
| **有出处** | 圈出照片里的某个东西、标出路线上的三个点、当手账贴纸成组贴上去、手写箭头指向一句话 | `random()` 撒满一页、每页右上角固定挂一个同款小方块 |
| **不整齐** | 轻微倾斜 ±1–5°、大小不一、手撕边、手绘线不闭合、叠压露角 | 四张等大、等距、同一圆角、同一投影排成一排 |
| **会变化** | 同种装饰全本 ≤2–3 次，且每次位置/数量/颜色不同 | 「四色圆点全本一致」当统一语言、每页同一模板 |

**一句话**：加上它之后更像「有人动过手」，就留；加上它之后更像「系统加了个组件」，就删。

## 三种仍然禁止的**组合**（用户圈的三张，禁的是组合不是零件）

### AP-1 徽章阵列
**禁的是**：4 张等大圆角小图 + 每张白边投影 + 中间波浪虚线连起来 + **彼此没有叙事关系**，
看起来只是「把剩下的图塞进四格」。
**不禁**：圆形裁切、白边贴纸、波浪线各自的单独使用。
**允许**：同场景连拍条；一张拍立得式白边小照片压在满版图角上；两张不同大小的圆图有主次。

### AP-2 填空色块
**禁的是**：单页 ≥40% 纯高饱和色 + 中间一个圆图 + **没有任何有实质内容的文字**。
色块是在替「留白」做决定。
**不禁**：高饱和荧光色做小面积点缀；淡色半透明纸压在照片上（色是载体、字是内容）。
**允许**：小面积荧光块配一句用户原话；淡色纸覆盖满版照片并承载一整段私话。

### AP-3 复制跨页 + 随机撒点
**禁的是**：**同一张图**在相邻两页各出现一次（左右各半或整张重复）＋随机撒点。
一张图印两遍是浪费，随机点不是手作。
**不禁**：成组有语义的波点；椭圆裁切；跨页本身。
**允许**：左右两页放**两张不同的相关照片**，共享一个主题或一行字；3 个点标出照片里的三个位置。

## 通用硬禁令（只保留真正硬的）

| 编号 | 规则 | 可判定条件 |
|---|---|---|
| AP-4 | **一张图全本最多出现 1 次** | `plan.json` 里任意 image id 出现次数 ≤1 |
| AP-8 | 禁止纯装饰文字 | 竖排版名、无意义编号、为填空写的短句一律不渲染；文字必须有归属（`interaction.md`） |
| AP-9 | 缺页**不复用照片** | 补页用 `BREATH` / `HANDWRITE_BIG` / `LINE_MAP` / 手作装饰页 |
| **AP-10** | **不许整本方方正正** | 连续 ≥3 页都是「纯直角矩形 + 精确对齐 + 无手工痕迹」→ 必须插一页带手作元素的页；全本至少 4 页出现手工痕迹 |

> AP-10 是本次新增，直接来自用户「太方方正正了」。**直角不是审美目标，只是其中一个选项。**

|---|---|---|
| **波点 / 彩色圆点** | 成组 2–5 个、有指向或节奏作用；全本 ≤3 页；颜色从本本双色里取，不固定四色全本一致 | v1 四色圆点；#3 一页橙点、#5 一页蓝点 |
| **圆形 / 椭圆裁切** | 一页最多 1 处，用在「值得被圈起来」的那张；可跨中缝 | v1 §4；#1 #4 里的椭圆 |
| **白边贴纸** | 拍立得 / 剪下来的纸片感，1–2 张，可轻微倾斜叠压；不要 CSS `box-shadow` 组件感 | v1 §3；#4 白边小照片 |
| **荧光 / 高饱和小点** | 小面积（≤10% 页面积）用一次，作为「跳」的那一下 | v1 荧光黄绿 `#E9F55C` |

| **椭圆跨页** | 可以跨，但左右是两张不同的相关照片 | v1 §9 修正版 |

## 引擎怎么检查

1. 遍历 `plan.json` 收集 image id → 任一 count > 1 失败（AP-4）。
2. 相邻两页 image id 交集非空 → 失败（AP-3）。
3. **组合判定**：同页 ≥3 张等大非直角小图 AND 全部带白边/投影 AND 有装饰连线 AND 无共同主题 → AP-1。
   （只看「有没有圆角」不算违规。）
4. 纯色面积 >40% AND 该页实质文字 <10 字 → AP-2。
5. **AP-10**：统计每页 `handmade` 标记（圆/椭圆裁切、成组波点、白边贴纸、手绘线、倾斜叠压、手撕边、手写圈注）；
   全本 <4 页命中，或存在连续 ≥3 页均无 → 失败，需换骨架重排。
6. 渲染后肉眼复核：整本看起来像「一个人动手摆过」还是「系统排了网格」。

> 这些检查应在生成 `plan.json` 之后、`zine.html` 之前跑，命中即换骨架重排，而不是出稿后靠人挑。
