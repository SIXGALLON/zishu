## 一、先说清楚错在哪

把「丰富」实现成「3 个风格包」，等于把连续的设计空间离散成 3 个套餐：
每个包锁死了配色 + 固定 3 个骨架，选完就没得换了。这比 v1 的 11 种骨架轮转**自由度更低**。

> 正确的抽象：**底层锁 4 项保证「是一套东西」，每页放开 5 类保证「页页不同」。**
> 丰富度 = 骨架 × 文字 × 照片处理 × 线条 × 装饰件的组合数；一致性 = 那 4 项全本不变。

## 二、锁定的底层（全本 4 项，由用户定或由我从参考取）

| 旋钮 | 可选值 | 说明 |
|---|---|---|
| 纸色 | 近白暖 `#FAF8F2` / 斑点米黄 `#F6EEDC` / 淡色纸 | 一本只用一个 |
| 双色组 | 粉×薄荷 `#F2C9D4`/`#A8D5C7`、浅黄×浅蓝 `#F3E9BE`/`#A9D6E5`、橙×青 `#E8A15C`/`#3E8E8C`、白×淡蓝 `#FAF8F2`/`#BFDDE8` 等 | 一本只用一组；可用户自定 hex |
| 线的语言 | 极细实线 / 手绘曲线 / 网格线 / 地图线 / 藤蔓线 / 无线 | 一本只用一种，线宽 0.3–0.6mm |
| 留白基调 | 紧凑 30–40% / 中等 40–55% / 松弛 55–65% | 一本只用一个基调，单页可浮动 ±10% |

这 4 项就是 `zine-dna-v2.md` §2.8 说的「一致性不靠每页同款装饰」。**只有这 4 项一致，其余全自由。**

## 三、每页自由调用的 5 类零件

### 1. 版式骨架（14 种，来自 `zine-dna-v2.md` §三；按「图／字关系」重排，不属于任何方向）

| 图字关系 | 骨架 |
|---|---|
| 只有图 | `FULL_PHOTO`、`CONTACT_STRIP`、`CONTACT_GRID`、`DUO_VERTICAL`、`POLAROID_PIN` |
| 图 + 字 | `SPLIT_SPREAD`、`NOTE_CARD`、`TRACE_OVERLAY`、`PAPER_COLLAGE`、`LINE_MAP` |
| 只有字 | `TITLE_VERT`、`HANDWRITE_BIG`、`TICKET_LIST`、`BREATH` |
| 开场／收尾 | `COVER_CUSTOM`、`BACK_CUSTOM`（属性见 §五） |

**任何一页都可以调用任何一种骨架**，不受「方向」约束；只受 §四的组合规则约束。

### 2. 文字旋钮（5 种，可叠加）
- 竖排中文大字 / 手写感散排大字 / 一整段私话 60–120 字 / 极小注 7–9pt / 打字机式编号清单
- 归属规则见 `interaction.md`：只放用户原话，来源标记 `user_verbatim` / `user_confirmed_guess` / `unfilled`

### 3. 照片处理（4 种，可逐页不同）
- 原色 / 轻褪色 / 黑白 / 局部黑白混排
- **裁切以直角为默认，不是禁令**：一页最多一处圆／椭圆裁切；白边拍立得 1–2 张、可倾斜叠压；
  禁的是 3 张以上等大带投影的徽章阵列（AP-1），不是白边或圆形本身。详见 `anti-patterns.md`。

### 4. 线条与涂鸦（6 种，可逐页选 0–2 个）
- 建筑／地图轮廓线、藤蔓卷草、网格、手绘箭头、几何圆与交点、圈出重点的线圈
- 线必须是**内容**（指向、路径、圈注），不做装饰分隔线

### 5. 装饰件（默认要有，不是可选）
- **波点／彩色圆点**（成组 2–5 个、有指向）、圆／椭圆裁切、白边贴纸、手绘波浪线／涂鸦／箭头、
  编号徽章／时间戳、手撕纸边、半透明色纸、荧光小点、轻微倾斜叠压
- 22:15 修正：这些是 zine 的玩心所在，**不能默认全关**，否则整本又变成方方正正的网格稿。
- 约束：有出处／不整齐／会变化（`anti-patterns.md` §零）；全本至少 4 页带手工痕迹（AP-10）；
  同种装饰 ≤2–3 次且每次形态不同；在版式清单里写明「这里我加了，可以说去掉」。
- 半透明色纸仍须承载真实文字；A 的粉色降权，但不禁用。

## 四、组合规则（保证丰富但不散架）

1. 一本只锁 §二 的 4 项；§三 的 5 类**每页独立自由**。
2. 相邻两页骨架不同；同一种骨架全本不超过 2 次。
3. 一张图全本最多出现 1 次（AP-4）；缺页用 `BREATH` / `HANDWRITE_BIG` / `LINE_MAP` 补，不复用照片（AP-9）。
4. 每页必须过 `anti-patterns.md` 的 AP-1…AP-10 检查，命中即换骨架重排。
   **特别注意 AP-10：不许整本方方正正**——连续 ≥3 页都是纯直角、精确对齐、无手工痕迹即判失败，
   必须插一页带波点/圆裁切/贴纸/手绘线/倾斜叠压的页。直角不是审美目标，只是选项之一。
5. 每 3–4 页至少出现 1 页「停顿」（纯字／留白／线描），形成呼吸节奏——依据 #3 #5 整本缩略里的页序节奏。
6. 跨页左右两页结构不同但共享一个主题或一行字；禁止同一张图左右各半（AP-3）。

**自由度估算**：14 骨架 × 5 文字 × 4 照片处理 × 6 线条 × 4 角色 ≈ 上千种页型；
底层一致性只有 4 个旋钮。这就是「比原来丰富，却不乱」。

## 五、封面／封底的自定义属性（加强，用户明确要求）

```
cover.image         指定哪张（不再自动取第一张）
cover.layout        满版图 / 小图大字 / 纯字 / 字压图 / 拼贴 / 留白
cover.title         用户原话
cover.sub           用户原话，可空
cover.ornament      线圈 / 线描 / 无（默认无）
back.image          指定哪张，可空
back.layout         淡色满版 / 剪影 / 一行字 / 纯留白 / 卡片
back.text           用户原话，可空
back.colophon       可空；不写就不渲染
```

全部能在对话里直接说，也会写进 `story.json`。默认不写任何用户没提供的信息。

## 六、A/B/C 三个样张的处置

| 样张 | 用户评价 | 拆出来的零件 → 去向 |
|---|---|---|
| A 日记感（粉×薄荷） | 不好 | 半透明色纸保留为**低频可选装饰件**，粉色降权；「一整段私话」这条文字旋钮**保留并提权**（对应 #2 参考） |
| B 旅行索引感 | 好 | 极细线描地图、竖排大字、左满版/右分格、浅黄×浅蓝 → **提权为高频零件** |
| C 摊开的卡片 | 好 | 直角卡片、大留白、一页一件事、白×淡蓝、2×2 网格、细线圆 → **提权为高频零件** |

> **不再有 `style=A/B/C` 这种参数。** 生成时接受的是：
> `palette`（一组双色）+ `paper` + `line_language` + `whitespace` + 每页 `skeleton` + 每页文字／照片处理。
> 用户若说「想要 B 那种感觉」，应翻译成「浅黄×浅蓝 + 地图线 + 竖排大字 + 分格小图」这组零件，
> 而不是套用一个叫 B 的模板。
