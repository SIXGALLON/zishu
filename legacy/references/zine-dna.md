## 一、先说最重要的判断

**这批参考里的 zine，不是「一本小杂志」，而是「一叠被整理过的生活采集物」。**

它不像杂志那样靠栏目、目录、长文、统一卡片建立秩序，而是靠三样东西：

1. **时间/地点/编号等极小的标签**（记录感）
2. **照片被当成「贴上去的物件」**（白边、圆形裁切、错落、可叠压）
3. **手工痕迹**（手写、手绘线、描图纸、印章、编号徽章、斑点纸）

我上一版 skill 做的 `quiet` 预设（暖米纸 + 黑白满版照片 + 衬线大字 + 长文分栏）**更像摄影画册，不像这批 zine**。这是必须推倒重来的地方。

## 二、三个子类型（不是一种风格）

| 类型 | 出现在 | 一句话 | 可判定特征 |
|---|---|---|---|
| **A · 采集 / 散步记录**（占多数，默认） | 1, 2, 4, 5, 6, 8, 9, 11, 12, 13, 15, 20 | 一次出门，把拍到的东西像标本一样排一页 | 白底 + 满版跨页照片 + 右栏圆形小图 + 时间地点 tiny 页眉 + 荧光黄绿块 + 彩色圆点 + 手写标注 + 编号徽章 |
| **B · 色块拼贴** | 19（及 1、6 的局部） | 高饱和纯色和照片各占一半，像贴纸卡片 | 2×2 单元；每单元 = 半页纯色 + 半页照片 + 小照片贴在色块上；色板钴蓝/荧光黄/绿/橙/紫/粉 |
| **C · 艺术家书 / 豆本** | 14, 16, 17（及 20 的局部） | 一页只放一个东西，纸本身是主角 | 斑点再生纸 + 米黄/淡黄淡绿色块 + 单个线描物件 + 硫酸纸半透明页 + 留白 80%+ + 极小段文字 |

**三者共用同一套骨架引擎，只换「纸 / 色 / 裁切 / 密度」四个参数。**

## 三、跨三类反复出现的 10 条共同元素

每条都写成「可以直接写进 SKILL.md 的可判定值」。

### 1. 纸永远不是纯白
- 取值：近白暖 `#FAF8F2`（A/B）／ 米黄带斑点 `#F6EEDC`（C）
- 出现：1, 2, 4, 9, 14, 16, 17, 20
- 规矩：**禁止 `#FFFFFF` 纯白背景**；C 型必须叠一层细密彩色斑点噪点（不是均匀灰噪点）。

### 2. 颜色极省：1 个高饱和强调色 + 黑白照片
- 取值：A 型荧光黄绿 `#E9F55C`；B 型从 `#2E6BE6 / #F5D400 / #3FA535 / #E08A1E / #6B1FA0` 轮转；C 型米黄 `#F3E2B8` / 淡绿 `#E9EED8`
- 圆点装饰用原色四件套：`#F5D400`（黄）`#3B7BE0`（蓝）`#E8462E`（红）`#2FA84F`（绿）＋黑、白
- 出现：1, 4, 6, 9, 19
- 规矩：**单页最多 1 个大面积彩色 + 1 个小面积彩色点缀**；禁止渐变（除 B 型一处粉绿渐变例外）；照片不必统一黑白，但整体要偏褪色。

### 3. 照片多为「小尺寸、带白边、像贴上去的」
- 取值：白边 1.5–2.5mm，轻微旋转 ±1–5°，可叠压在满版图上，可压细阴影
- 出现：2, 4, 9, 13, 20
- 规矩：**每本至少 3 页出现贴纸式小图**；满版图只用在跨页、情绪页、章节页，不能张张满版。

### 4. 圆形 / 椭圆 / 圆角裁切是标志性手法
- 取值：正圆 `border-radius:50%`；椭圆（第 4 张下半，横跨中缝）；圆角矩形 `border-radius:8–14mm`
- 出现：1, 4, 6, 9, 19
- 规矩：**每本至少 2 处非直角裁切**；直角照片只用于满版页。

### 5. 极小的「页眉 / 采集标签」
- 取值：7–8pt，全大写英文或竖排中文，内容形如 `SEOUL TRIP 0430` / `WANGWONHANGANG PARK · YANGHWA BRIDGE · 0429 16:40` / `Sep. 2025` / `骆山公园`
- 出现：2, 4, 6, 9, 20
- 规矩：**每页页眉固定一个 tiny 标签**（地点 + 日期 + 时间/编号），位置在顶边或竖排左边；这是「记录感」最主要来源。

### 6. 时间 / 编号 / 清单混排
- 取值：散落时间戳 `17:39 / 21:58 / 20:00`；编号徽章 `6 / Th / △5`（小三角或小方块底）；底部 3–5 行项目符号清单
- 出现：4, 6, 9
- 规矩：不用规整页码，改用「采集编号」；每本至少 1 页出现清单或时间戳。

### 7. 手工痕迹：手写、手绘线、描图纸
- 取值：手写英文短句、手绘波浪连线、山形轮廓白线、半透明硫酸纸覆盖层（白色 45% 透明）
- 出现：2, 4, 9, 14, 17, 20
- 规矩：允许「不精确」；细线宽 0.3–0.6mm；手写体只做点缀，不做正文。

### 8. 大量留白，一页只讲一件事
- 取值：A 型留白 30–55%，C 型 75–90%
- 出现：2, 9, 14, 16, 17, 20
- 规矩：**禁止「满版图 + 长文」同页**；长文字必须拆成短句分散到多页。

### 9. 跨页（spread）才是基本单位
- 取值：照片横跨中缝；左右页共用一条页眉；中心跨页放最强的一张图或椭圆裁切
- 出现：2, 4, 6, 9, 13, 20
- 规矩：中心两页必须成对设计；拼版时页码仍按 saddle_order 排（见 imposition.md）。

### 10. 文字极少，几乎没有长文
- 取值：一句短句（≤16 字）／ 一行图注（≤80 字）／ 3–5 行清单；正文 8–9pt，标题 20–38pt
- 出现：全部 20 张
- 规矩：**取消「双栏长文页」**。超过 80 字的文字一律自动切句，分散成多页短句，不排成文章。

## 四、反例清单（从 6 张商业模板图里数出来的，明确禁止）

| 商业杂志语言 | 为什么不属于这批 zine |
|---|---|
| 封面条码、期号 + 条形码 | 参考里没有零售逻辑 |
| 目录页、编者话、多作者署名 | 参考里没有栏目结构 |
| 双栏 / 三栏长文、段落样式 | 参考里几乎没有成段文字 |
| 统一圆角卡片 + 淡阴影 | 参考里是白边贴纸，不是卡片组件 |
| 大字号广告式标题铺满封面 | 参考里标题细小、常竖排或压在角落 |
| 精细对齐的栏目网格 | 参考里是错落、可轻微歪斜的采集式排布 |
| 每页一个统一模板 | 参考里每页骨架都不同，靠 tiny 标签串起一致性 |

> 一致性不靠「每页长一样」，靠**每页都出现同一种 tiny 页眉 + 同一种圆点/编号语言**。这是这批参考最反直觉、也最该写进 skill 的一条。

## 五、形容词 → 参数对照（写进 SKILL.md 时用）

| 人话 | 可判定值 |
|---|---|
| 「有记录感」 | 每页 tiny 页眉（地点+日期+时间）+ 至少 1 页时间戳或清单 |
| 「像贴上去的」 | 白边 2mm + rotate(-3°~3°) + 细阴影 0 1mm 2mm rgba(0,0,0,.18) |
| 「有点跳」 | 单页 1 个高饱和色块，面积 ≤40%，颜色从 5 色轮转表取 |
| 「手工感」 | 手绘波浪线 SVG path + 至少 1 个编号徽章 + C 型斑点纸 |
| 「别太满」 | 留白 ≥30%（A/B）或 ≥75%（C）；禁满版图与长文同页 |
| 「一套东西」 | tiny 页眉字体/位置全本一致；圆点四色全本一致；编号徽章形状全本一致 |

## 六、与旧版 skill 的差异（为什么重做）

| 项 | 旧版 quiet / xerox / riso | 依据新参考重做后 |
|---|---|---|
| 纸 | 暖米 `#F5F0E6` | 近白暖 `#FAF8F2` / 斑点米黄 `#F6EEDC` |
| 照片 | 一律黑白滤镜、张张满版 | 轻褪色、多数小尺寸带白边、圆形/椭圆裁切 |
| 文字 | 长文双栏分栏页 | 取消；切成短句分散 |
| 颜色 | 黑白 / 双专色 | 1 个荧光/高饱和 + 四色圆点 |
| 一致性 | 页码 | tiny 页眉 + 编号徽章 + 圆点语言 |
| 装饰 | 噪点、套印错位 | 手绘线、时间戳、清单、贴纸、硫酸纸 |
| 页单位 | 单页 | 跨页成对设计 |
