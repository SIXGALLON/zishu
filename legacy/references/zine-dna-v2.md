## 一、核心判断：v1 抓错了重点

v1 是从一批**小红书模板合集截图**里数出来的，数到的是「白边贴纸／圆形裁切／彩色圆点／高饱和色块」。
这些元素本身没错，错的是 v1 把它们**机械地、每页同款地**用；用户圈出的三张反例也是「摆法」坏，不是零件坏。
纠正（22:15）：**不能因此把装饰全禁掉，否则就变成方方正正的网格稿。**

> **照片不必一律直角；动手脚的是「纸、字、线、贴」四层，而且每一层都承载本人要说的话。**
> 直角只是选项之一；波点、圆／椭圆裁切、白边贴纸、手绘线、轻微倾斜都要回来，
> 但须满足「有出处／不整齐／会变化」（`anti-patterns.md` §零），且全本至少 4 页有手工痕迹（AP-10）。

| v1 的用法（坏在哪） | 该改成（不是禁掉） |
|---|---|
| 4 张等大白边圆角贴纸排成徽章阵列 | 1–2 张拍立得式白边小照片，有主次、可倾斜叠压 |
| 圆形／椭圆裁切每页都用、每页同款 | 一页最多一处，用在「值得被圈起来」的那张 |
| 四色圆点随机撒满、全本一致 | 成组 2–5 个、有指向，全本 ≤3 页且每次形态不同 |
| 大面积高饱和色块 | 低饱和淡色双色；且常是**半透明压在照片上**，不是纯色填空 |
| 文字极少、只放 ≤16 字短句 | 有完整一段私人叙述、对话引号、竖排中文大字——**文字是主角之一** |
| 每页统一 tiny 地点日期页眉 | 多数页没有统一页眉，靠「同一套淡色 + 同一种极细线 + 同一种留白比例」统一 |
| 跨页 = 一张图左右各半 | 跨页 = 左右两页结构完全不同，但共享一个主题／一行字 |
| 手工感 = 波浪线 + 编号徽章 | 手工感 = 手绘极细线、手写大字、半透明纸、拼贴错位、涂鸦 |

## 二、10 条审美元素（写成可判定值）

### 1. 淡色双色系统，不是高饱和单色
- 从图里取的三组主色（近似 hex，非官方色卡）：
  - A 粉 × 薄荷：`#F2C9D4` / `#A8D5C7`（#1 #2）
  - B 浅黄 × 浅蓝：`#F3E9BE` / `#A9D6E5`（#5 关西寻夏）
  - C 橙 × 青：`#E8A15C` / `#3E8E8C`（#3 部分页）
- 规矩：**一本只用一组双色**；纸底保持近白暖 `#FAF8F2`；禁 `#FFFFFF` 纯白；禁高饱和荧光色。

### 2. 半透明色纸覆盖在满版照片上（最标志性）
- #2：满版直角照片（树林长椅）上压一块大的淡粉／薄荷半透明矩形，字写在矩形里，矩形内还嵌一小段照片。
- 参数：色纸不透明度 70–85%，可跨中缝；矩形直角、可轻微倾斜 ≤2°；下缘／侧边可露出底图。
- 规矩：**色是载体，字是内容**；没有实质文字就不许铺色纸（防 AP-2）。

### 3. 照片以直角为主，但不必一律直角（22:15 修正）
- 直角是**默认**，不是禁令；一页最多一处圆／椭圆裁切，用在「值得被圈起来」的那张。
- 白边可以有，但要是拍立得／剪下来的纸片感，1–2 张、可轻微倾斜叠压；
  禁的是 3 张以上等大带投影的徽章阵列（AP-1），不是白边本身。
- 不默认黑白化；可轻褪色但保留原色。
- 尺寸不止两种极端：满版、整齐排格、**贴纸式小图**（有主次、有叠压）都应可用。
- 全本至少 4 页出现手工痕迹（AP-10）；不许连续 3 页都是纯直角、精确对齐、无手作元素。

### 4. 文字是主角，允许「有话要说」
- 允许：一段 60–120 字的私人叙述、带引号的对话、口语和标点、没说完的半句（#2）。
- 允许：竖排／散排中文手写感大字（#1「这您得（胡同）溜着边儿走」「北京。」、#5「关西寻夏」「大阪城公园」）。
- 规矩：**取消 v1「文字极少、超 80 字一律切碎」**；长文可整段放在色纸／留白页，但一页只放一段。
- 文字归属见 `interaction.md`：只放用户原话，不润色、不代写。

### 5. 极细手绘线（0.3–0.6mm）
- 出现形式：建筑／地图轮廓线（#5）、藤蔓卷草（#4）、网格与灯串线（#1）、涂鸦曲线与箭头（#2 #3）、几何圆与交点（#4）。
- 颜色：白（压在照片上）或主色深色（压在纸上）。
- 规矩：线是**内容**（地图、路径、指向、圈出重点），不是装饰分隔线；禁等距波浪虚线。

### 6. 实物拼贴式错位
- #1：底图上叠两张直角彩纸 + 一张直角照片，轻微倾斜、彼此叠压，像真的用胶水贴过。
- 参数：倾斜 ±1–5°，叠压面积 10–30%，纸片边缘可有细小手撕／笔触痕。
- 规矩：**倾斜的是「纸片」，不是「照片」**；照片本身保持端正（防 AP-1）。

### 7. 跨页 = 两个不同结构共享一个主题
- #5 每个跨页：左满版林荫 / 右三张竖排小图；左线描大字 / 右城堡照片；左线描地图 / 右蓝色小图组。
- 规矩：**禁止左右同一张图**；左右各自成立，靠同一组双色、同一行小字或同一条细线连起来。

### 8. 每页结构都不同，一致性靠「底层语言」
- #3 的 16 页：橙色封面、索引格、水面人像＋涂鸦、海岸＋留白、拍立得＋手绘树、棕色满版＋食物小照、黑白满版＋红半圆、线描地图＋三格小图……
- 统一靠：同一组双色、同一种极细线、同一种留白比例（30–60%）、同一种极小字字号。
- 规矩：**不靠每页同一个 tiny 页眉**，也不要连续两页同骨架。

### 9. contact sheet 式直角小图网格
- 2×2 / 2×3 / 3×3，格间 2–4mm 细白线，四周留白 12–20mm，每格可挂一个极小编号。
- #4 的蓝底 2×2 黑白小图、#5 的 Kobe 2×3 灰调小图、#3 的索引页。
- 规矩：组内小图必须**来自同一场景／同一件事**（呼应「有关联的该放一起」）。

### 10. 温暖 = 不急着填满
- 允许一页只有一张图 + 一行字，允许整页留白，允许一句话带句号、带口误、带没想好。
- 规矩：留白 30–60%（不是 v1 的 75–90% 极端留白），禁「满版图 + 长文」同页，禁为凑页数复用照片（AP-9）。

## 五、诚实标注

- 5 张都是手机截图，#3 #5 是缩略网格，格内小字无法逐字 OCR，因此「文字量／结构类型」按可见版式归纳，不冒充逐字内容。
- hex 是从图上取的近似值，非官方色卡；#1 #2 的粉色／薄荷绿因叠在照片上，实际取值受底图影响，仅作工程起点。
- #1 的中文字（「这您得（胡同）溜着边儿走」「北京。」）按手写大字处理，未做字体识别；skill 应提供手写感字体族，不复制原字形。
- 黑底、`1/14` 相册页码、关闭按钮是平台 UI，未计入设计元素。
- 尚未验证：新骨架在 A5 骑马钉 16 页下的实际渲染效果，需出 3 页样张确认。
